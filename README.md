# TrackMySaving – Business Analysis Case Study

## Project Overview
TrackMySaving is a personal finance and retirement planning mobile application designed to help users manage budgets, savings, investments, and long-term financial goals.

## My Role
Business Analyst 

## Responsibilities
- Conducted client meetings and requirement elicitation sessions
- Performed stakeholder analysis and defined product scope
- Authored 27+ feature-wise BA documents including BRD, FRD, user stories, workflows, and acceptance criteria
- Acted as the primary liaison between clients and development team
- Supported developers with requirement clarification and change management

## Key Modules Covered
- Budget & expense management
- Credit card tracking
- Retirement planning & projections
- Analytics dashboards
- Admin & reporting features

## Tools & Methods
- Requirement Documentation (BRD, FRD)
- User Stories & Acceptance Criteria
- Stakeholder Workshops
- Agile Practices
- Figma (supporting flows & visuals)
